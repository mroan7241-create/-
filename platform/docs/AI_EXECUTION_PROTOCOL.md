# بروتوكول تنفيذ ثابت (AI Execution Protocol)

قواعد مستقرة تحكم كل مرحلة NODE-N/patch في هذا المستودع، مستخلَصة من الممارسة الفعلية عبر NODE-1..NODE-4. هذا الملف مرجعي — لا يُنقَض لاحقًا إلا بقرار صريح موثَّق.

1. **GitHub هو Source of Truth.** لا عمل يُعتبَر منجزًا قبل commit + push فعليَّين على الفرع المحدَّد. لا نشر (deploy) يحدث ضمن أي مرحلة ما لم يُطلَب صراحة.
2. **Baseline دقيق.** كل مهمة تبدأ من SHA مُعتمَد صراحةً — يُتحقَّق منه (`git rev-parse HEAD`) وأن الشجرة نظيفة (`git status --porcelain`) قبل أي تعديل. عدم التطابق = توقّف فوري بلا أي تعديل.
3. **TypeScript صارم.** لا `any` غير مبرَّر، لا casts للتحايل على تحقق فعلي. الأخطاء المرفوضة تُصلَح عند الجذر لا بإسكاتها.
4. **عزل المستأجرين (tenant isolation).** `associationId` لفاعل ASSOCIATION يأتي من `AuthContext` فقط — أبدًا من body/query. وصول جمعية لمورد جمعية أخرى يُرَد بـ404 (لا 403) لمنع enumeration.
5. **تحقق زمن تشغيل حقيقي.** كل معامل HTTP (pagination، enum، UUID) يُتحقَّق عبر DTO + Pipe فعلي (`ParseUUIDPipe`، `class-validator`)، لا cast TypeScript وحده. لا قيمة خارج النطاق تصل إلى Prisma خامًا.
6. **حدود المعاملات (transaction boundaries).** كل عملية كتابة مركّبة (إنشاء+ترقيم+علاقات) تحدث داخل `prisma.$transaction` واحدة. القفل الصفّي (`SELECT ... FOR UPDATE`) يُستخدَم حيث يوجد تزامن حقيقي محتمل على نفس السجل.
7. **مراجعة التزامن/TOCTOU إلزامية.** أي فحص-ثم-كتابة (check-then-write) يُعاد فحصه تحت تزامن حقيقي (لا محاكاة) قبل اعتباره آمنًا.
8. **بصمة idempotency قانونية (canonical).** الحمولة المُمرَّرة لـ`IdempotencyService.claim` لا تحتوي أبدًا: طابعًا زمنيًا مولَّدًا وقت التنفيذ، مفتاح كائن تخزين عشوائيًا، أو أي قيمة تتغيّر بين استدعاءين "متطابقين منطقيًا". فقط محتوى الطلب القانوني (sha256 للملفات، قيم مطبَّعة).
9. **ملفات خاصة دائمًا.** لا bucket عام، لا رابط دائم، لا base64 في DB. الوصول فقط عبر رابط موقَّع قصير العمر أو streaming محروس، بعد تحقق ملكية صريح.
10. **تنظيف تعويضي (compensating cleanup).** أي رفع كائن ناجح يتبعه فشل DB لاحق (حتى تعارض idempotency) يستوجب حذف best-effort للكائن المرفوع — لا كائن يتيم كسلوك طبيعي.
11. **حدود الترقيم (pagination bounds).** `page`/`pageSize` محدودان صراحة (`MAX_PAGE`/`MAX_PAGE_SIZE`) مع رفض 400 نظيف لأي تجاوز — لا clamp صامت.
12. **لا N+1.** أي عدّاد/تجميع لكل صف في قائمة مُرقَّمة يُبنى عبر استعلام batched واحد (`groupBy` أو مكافئه)، لا استعلام منفصل لكل صف.
13. **لا Bootstrap ضخم.** كل صفحة تجلب بياناتها عبر REST endpoint خاص بها، مُرقَّم خادميًا — لا تحميل كامل مجموعة البيانات إلى الواجهة ثم الفلترة محليًا.
14. **الأداء/الخفة شرط قبول.** لا مكتبات UI ثقيلة جديدة، لا إعادة تحميل كامل للصفحة عند تفاعل عادي، حالات تحميل/خطأ واضحة.
15. **اختبارات مستهدفة أثناء التطوير، الحزمة الكاملة قبل الالتزام النهائي.** التكرار السريع يستخدم تشغيل ملفات اختبار محدَّدة فقط؛ الانحدار الكامل (unit + DB integrity + e2e + storage + builds) يُشغَّل مرة واحدة قبل commit.
16. **CI يملك القرار النهائي على الانحدار الشامل.** الجلسة المحلية تكتفي بتشغيل مستهدف + حزمة كاملة مرة واحدة؛ لا polling متكرر على GitHub Actions إلا إن طُلِب صراحة.
17. **لا بدء مرحلة NODE تالية تلقائيًا.** كل مرحلة/patch يتوقف عند حدوده المصرَّح بها فقط.
18. **تقارير ختامية موجزة وصادقة.** الأرقام (عدد الاختبارات، الحالة) تُقاس فعليًا لا تُقدَّر، والانحرافات المتعمَّدة عن Legacy تُوثَّق صراحةً بدل إخفائها.
